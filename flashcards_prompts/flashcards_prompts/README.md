# Dossier de prompts - Flashcards EN

Ordre à suivre :
1. Copier `.github/copilot-instructions.md` à la racine du projet Flutter (Copilot le lit tout seul). Avec Gemini seul, coller `00_CONTEXTE.md` en premier.
2. Faire les prompts 01 à 19 dans l'ordre, un fichier à la fois. Après chaque étape : `flutter analyze`.
3. Lancer : `flutter run --dart-define=GEMINI_KEY=ta_cle`

Ne jamais commiter la clé Gemini.
