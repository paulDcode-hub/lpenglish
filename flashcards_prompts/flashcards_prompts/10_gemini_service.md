# 10 - lib/services/gemini_service.dart

## Prompt
Crée `lib/services/gemini_service.dart` avec `class GeminiService` (méthodes statiques) utilisant le package `http` et l'API REST Gemini.
- Constantes : `_key = String.fromEnvironment('GEMINI_KEY')`, `_model = 'gemini-2.5-flash'` (facile à modifier, commentaire "vérifier le nom du modèle actuel"), URL `https://generativelanguage.googleapis.com/v1beta/models/$_model:generateContent`, clé passée dans l'en-tête `x-goog-api-key`.
- Méthode privée `_generateJson(String prompt)` : POST, `generationConfig: {responseMimeType: 'application/json', temperature: 0.7}`, timeout 30 s, extrait `candidates[0].content.parts[0].text`, `jsonDecode`, lève une `Exception` lisible en français si clé absente, erreur réseau, statut != 200 ou JSON invalide.
- `static Future<List<GrammarExercise>> generateGrammarExercises({String? theme, List<String> weakThemes = const []})` : demande 10 exercices à trous d'anglais niveau A2-B1. Le prompt (en français) impose ce JSON strict : `{"exercises":[{"sentence":"She ___ to school every day.","answer":"goes","accepted":["goes"],"theme":"Temps","explanation":"Présent simple, 3e personne : +s."}]}`. Un seul trou "___" par phrase, réponse courte (1-3 mots), thèmes limités à ceux de l'app (Temps, Modaux, Comparatifs, Articles, Prépositions), si `theme` est fourni tous les exercices portent dessus, sinon insister sur `weakThemes`. Valide que la liste contient 10 éléments, sinon lève une exception.
- `static Future<Map<String,dynamic>> optimizeSrs({required Map<String,double> params, required List<Map<String,dynamic>> wordStats, required Map<String,double> themeAccuracy})` : envoie les paramètres actuels, les stats de mots (id, en, reps, lapses, ease, interval), la précision par thème, et demande en JSON strict : `{"interval_modifier":1.1,"lapse_penalty":0.2,"priority_word_ids":[3,8],"weak_themes":["Temps"],"comment":"..."}` avec des règles claires (augmenter interval_modifier si précision globale > 85 %, le baisser si < 65 %, max 15 mots prioritaires).
Définis aussi la classe `GrammarExercise` (sentence, answer, accepted List<String>, theme, explanation) avec `fromJson` dans le même fichier.
